# Multidash is now Dashral

This project has moved and been renamed. Development continues at **[hasralgana/dashral](https://github.com/hasralgana/dashral)**, with its docs at **[dashral.com](https://dashral.com)**.

Dashral is the same project, grown up: accessible React components with motion editions, free blocks, and a Next.js admin dashboard template, built on Tailwind CSS v4 and installable through a shadcn registry.

- Code: [github.com/hasralgana/dashral](https://github.com/hasralgana/dashral)
- Components, blocks and templates: [dashral.com](https://dashral.com)
- Live demo: [demo.dashral.com](https://demo.dashral.com)

This repository is archived and no longer updated. Its code is kept as it was for anyone who used it, under the same license. New work, fixes and releases happen in Dashral.
